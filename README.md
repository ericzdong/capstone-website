# Google AI Agents & A2UI Capstone Website

A responsive Angular Material showcase site for the University of Louisville capstone project.

## Run locally

```bash
npm install
npm start
```

Then open `http://127.0.0.1:4200/`.

## Production build

```bash
npm run build
```

The production files are generated in `dist/capstone-site/`.

## Current sections

- Project introduction
- Why Storybook-to-A2UI conversion matters
- Four-stage export pipeline
- Project milestones
- Technical highlights
- Team
- Acknowledgments

The first version intentionally omits team photography, project screenshots, demo links, and repository links until those assets are finalized.
